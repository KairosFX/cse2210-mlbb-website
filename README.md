# Mobile Legends: Bang Bang — Beginner's Guide

A CSE2210 personal-interest website about **Mobile Legends: Bang Bang**, built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — Introduction and objectives (Turtle and Lord)
- `page1.html` — Hero roles
- `page2.html` — Emblems and talents
- `page3.html` — Laning and gameplay phases

## How to view

Open `index.html` in a web browser, or run the project with VS Code Live Server.

## Features

Four linked pages, interactive role/emblem/phase descriptions and icons, gameplay tips, question-and-answer toggle, and a shared stylesheet.

Some in-game artwork belongs to the respective game creators.
